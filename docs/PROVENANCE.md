# Provenance and third-party material

- **Original work.** All source code in this repository was written for True North Taktics Inc., independently, on personal time and equipment. It contains no code, designs or data from any current or former employer, client or partner.
- **No controlled material.** No NATO, MTF-XML, USMTF, NIEM-restricted, government-furnished, classified or controlled-goods material was used. Schemas, message structures and sample data are representative and synthetic.
- **Public sources only.** The 9-line MEDEVAC and SALUTE spot report structures follow publicly available descriptions. Reed-Solomon coding (Reed and Solomon, 1960) and the Vandermonde-based systematic construction come from the open literature. Cursor-on-Target follows the publicly documented CoT 2.0 event schema.
- **Third-party software.** None at run time. JUnit 4.13.2 (EPL 1.0) is used only for tests.
