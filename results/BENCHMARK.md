# Benchmark results

Generated by `bench` (`gradle :bench:run`). Synthetic, unclassified messages; representative link profiles from `docs/LINK_PROFILES.md`. Seed 20261010, 10000 trials per loss scenario. Java 21.0.8.

`schema/gateway-exchange-1.xsd` is generated from the message definitions. Each sample's XML exchange output is validated against it with the JDK's W3C XML Schema validator:

## 2. Delivery over lossy one-way links (no retransmission)

Each trial encodes the MEDEVAC request (precedence IMMEDIATE), fragments it for the link, drops fragments according to the loss model, then attempts real reassembly and decoding. A trial succeeds only if the decoded message equals the original. "No FEC" needs every fragment; "RS FEC" uses the standard precedence policy (IMMEDIATE = 100% parity) and needs any k of n fragments.
